# 裕珍皇 案場主機 (Mini PC) 建置與標準作業程序 (SOP)

> **適用對象**：現場工務工程師、系統整合商 (SI)  
> **適用主機**：Intel N100 / N95 / Core i3 等 Windows 11/10 迷你電腦  
> **作業時長**：約 30 分鐘（行前 15 分鐘 ＋ 現場 15 分鐘）

---

## 📌 作業流程總覽 (4 大階段)

```
[階段一：行前準備與初設] (出發前/辦公室)
   ├── 1. Windows 初設與自動登入
   ├── 2. BIOS 開啟「通電自動開機 (Auto Power On)」
   ├── 3. 電源計畫設為「永不睡眠」
   └── 4. 部署 Python 環境與 SCADA 專案包
         │
[階段二：案場硬體定位與接線] (抵達案場)
   ├── 1. 主機壁掛/鎖附於電視牆後方或電盤架
   ├── 2. 插上 RJ-45 網路線 (直連 W610 交換機)
   └── 3. 連接 HDMI 螢幕線與電源
         │
[階段三：網路靜態 IP 設定與網關通訊驗證]
   ├── 1. 網卡設定靜態 IP (192.168.68.100)
   └── 2. Ping 測試 W610 (192.168.68.200:2000)
         │
[階段四：一鍵啟動、開機常駐與斷電驗收]
   ├── 1. 執行 start_local.bat 啟動監控
   ├── 2. 設定開機自動啟動 (shell:startup)
   └── 3. 實測「拔插頭斷電復歸」自動拉起全螢幕電視牆
```

---

## 階段一：行前準備與軟體初設（出發前在辦公室完成）

### 1. Windows 初始設定
* 建立本機管理員帳號（如 `yjh-admin`）。
* 設定開機免密碼自動登入：
  * 按 `Win + R` ➔ 輸入 `netplwiz` ➔ 取消勾選「必須輸入使用者名稱和密碼」➔ 套用並輸入密碼儲存。

### 2. BIOS 工控設定（關鍵！工廠跳電復原必備）
1. 重開機時狂按 `Del` 或 `F2` 進入 BIOS。
2. 找到 **Power Management**（電源管理）或 **Advanced**（進階設定）。
3. 將 **`Restore on AC Power Loss`** 或 **`Auto Power On`** 設定為：**`Power On`** 或 **`Always On`**（通電自動開機）。
4. 按 `F10` 儲存並離開。

### 3. 電源與休眠管理（防止主機半夜睡著）
* 開啟「控制台」➔「電源選項」➔ 選擇 **「高效能」**。
* 設定：
  * **關閉顯示器**：設為 `永不`（或電視牆依需求）。
  * **讓電腦進入睡眠狀態**：**`永不`**。

### 4. 軟體環境安裝
1. 安裝 **Python 3.11 或 3.12**（安裝時務必勾選 **`Add Python to PATH`**）。
2. 安裝 **Google Chrome** 瀏覽器。
3. 將專案程式包複製至主機根目錄：`C:\YJH_SCADA\`。
4. 開啟 PowerShell 進入 `C:\YJH_SCADA\` 執行依賴安裝：
   ```powershell
   pip install -r requirements.local.txt
   ```

---

## 階段二：案場實體定位與線路連接（現場安裝）

1. **實體固定**：
   * 使用主機附帶的 VESA 壁掛架，鎖在電視牆大螢幕後方或配電箱專用設備托盤上。
2. **線路連接**：
   * 🔌 **電源線**：插上現場插座（建議接在有不斷電系統 UPS 之插座）。
   * 🖥️ **HDMI 視訊線**：連接電視牆或監控大螢幕。
   * 🌐 **RJ-45 網路線**：插上小電腦 LAN 網孔，另一端接至工業乙太網交換機（該交換機已連接 USR-W610 網關）。

---

## 階段三：網路 IP 配置與通訊驗證（現場調試）

### 1. 設定小電腦有線網卡靜態 IP
* 開啟「網路和網際網路」➔「乙太網路」➔「編輯 IP 設定」➔ 改為 **手動 (IPv4)**：
  * **IP 位址**：`192.168.68.100` *(請避開 .200)*
  * **子網路遮罩**：`255.255.255.0`
  * **預設閘道**：`192.168.68.1`
  * **慣用 DNS**：`8.8.8.8`

### 2. 測試 Modbus 網關連通性
開啟 PowerShell 執行連線測試：
```powershell
# 1. 測試網關 IP 是否在線
ping 192.168.68.200

# 2. 測試 Modbus TCP 2000 埠號是否通暢
Test-NetConnection 192.168.68.200 -Port 2000
```
* 看到 `TcpTestSucceeded : True` 即代表現場 RS-485 網關通信 100% 正常！

## 階段四：一鍵啟動、開機常駐與驗收交付

### 1. 啟動監控系統
在 `C:\YJH_SCADA\` 目錄下，滑鼠雙擊執行 **`start_local.bat`**。
* 系統會自動拉起地端 Web 服務（Port 88）與 Modbus 採集器。
* 自動開啟 Chrome 瀏覽器導向 `http://localhost:88`。

### 2. 現場畫面與數據驗收檢查表
- [ ] **庫溫數據**：12 路庫溫與盤管溫數值是否正常跳動（非 `--°C`）。
- [ ] **電表數據**：首頁「廠區電表資訊」即時功率 (kW)、當月累積耗電量 (kWh)、電流 (A)、電壓 (V) 是否正常跳動。
- [ ] **連線指示燈**：右上角通訊狀態顯示綠燈「正常連線」。
- [ ] **電視牆設定**：點擊「電視牆螢幕設定」➔ 選擇現場螢幕解析度（如 `1920x1080`），按鍵盤 **F11** 進入無邊框滿版全螢幕模式。

### 3. 設定 Windows 開機自啟動（無人值守常駐）
1. 按 `Win + R` ➔ 輸入 **`shell:startup`** ➔ 按 Enter 打開「啟動」資料夾。
2. 將 `C:\YJH_SCADA\start_local.bat` 建立捷徑，並將捷徑拖入「啟動」資料夾中。

### 4. 斷電驗收測試（驗證防護力）
1. **直接拔掉小電腦電源插頭**（模擬工廠跳電）。
2. **重新插回電源插頭**。
3. **驗收標準**：
   * 主機自動開機進入 Windows。
   * 自動登入桌面並在 30 秒內自動拉起 Web 監控畫面。
   * 歷史數據無任何損毀、運轉時數接續累加。
