## 第一章：系統定位與整體架構總覽

### 1.1 系統定位
「添利智慧冷鏈監控系統」專為食品生鮮、低溫倉儲及急速冷凍加工廠設計，融合現代物聯網（IoT）與雲端/邊緣雙核心架構。  
系統打破傳統老舊單機 SCADA 封閉、難維護、缺乏彈性的缺點，提供**地端電視牆即時看板、行動端遠端監控、雲端數據備援、毫秒級異常警報與遠端智慧控溫**的一體化解決方案。

### 1.2 雲地雙核心通訊架構
整套系統由五層鏈路緊密相扣：
1. **現場硬體層**：各冷凍庫/冷藏庫之物聯網溫控器（IoT-627）與廠區集合式多功能電表（SPM-3），透過 RS-485 實體雙絞線連接至現場通訊閘道器。
2. **通訊閘道層**：現場兩座無線閘道器（1F GW1、3F GW2），負責將 RS-485 Modbus RTU 訊號封裝為 TCP 封包，主動連網撥入雲端伺服器。
3. **雲端伺服器層 (GCP Cloud)**：部署於 Google Cloud Platform 雲端虛擬機，提供 24 小時不中斷的高速輪詢引擎，負責處理設備數據採集、連線狀態檢測與遠端控制指令下發。
4. **雲端資料庫層 (Supabase)**：採用銀行級 TLS 加密的雲端資料庫，實現最新狀態暫存、歷史數據冷熱分層與遠端命令佇列管理。
5. **地端監控大畫面層**：廠區電視牆/監控主機運行專屬 Web 監控引擎，每秒即時同步數據，提供流暢、免安裝瀏覽器即開的大畫面戰情體驗。

### 1.3 廠區點位分佈與監控範圍
本案場共涵蓋 14 個核心監控點位：
* **1 樓廠區（GW1 閘道器，通訊埠 8801）**：
  * `ch01`：1F 冷凍庫 A（溫控器 Slave ID 1）
  * `ch02`：1F 冷凍庫 B（溫控器 Slave ID 2）
  * `ch03`：1F 冷凍庫 C（溫控器 Slave ID 3）
  * `ch04`：1F 冷凍庫 D（溫控器 Slave ID 4）
  * `ch05`：1F 冷凍庫 E（溫控器 Slave ID 5）
  * `ch06`：1F 緩衝庫 A（溫控器 Slave ID 6）
  * `ch07`：1F 碼頭區 A（溫控器 Slave ID 7）
  * `ch13`：1F 集合式多功能電表（電表 Slave ID 8）
* **3 樓廠區（GW2 閘道器，通訊埠 1883/8802）**：

## 第二章：主監控大畫面（戰情中心首頁）功能說明

> **【📷 建議截圖處 1】**：首頁全景畫面（包含頂部狀態列、中央庫房卡片矩陣、底部智慧電表卡片）。

### 2.1 頂部全廠綜合狀態列
大畫面最上方為全廠狀態即時摘要，操作人員可於 1 秒內掌握全廠低溫健康度：
* **企業標誌與系統名稱**：左側展示公司企業標誌與當前系統名稱。
* **設備連線統計**：以分數形式顯示（例如：`8 / 14`），代表「目前正常回傳數據之點位數 / 全廠總點位數」。
* **狀態燈號統計**：
  * 🟢 **正常 (OK)**：溫度維持在安全門檻內之庫房數量。
  * 🔴 **警報 (ALARM)**：溫度超出安全上限/下限、或設備回傳故障碼之異常數量。
  * ⚪ **離線 (OFFLINE)**：逾時未回應之設備數量。
* **網關連線監控 (Gateway Status)**：
  * 明確列出 1F 網關與 3F 網關各自的連線狀態（正常 / 離線）。
  * 採顯式連線管理，單一溫控設備關機或故障，不會誤判整座網關斷線。
* **警報靜音按鈕 (消音鍵)**：
  * 當全廠有任一庫房觸發警報時，此按鈕會自動浮現並伴隨警報音效。
  * 點擊「靜音」可暫時關閉現場警報聲響，避免持續聲響干擾現場人員排查問題。
* **時鐘顯示**：顯示當前標準台灣時間（精確至秒），供確認畫面即時刷新無延遲。

### 2.2 庫房即時溫度卡片 (矩陣視圖)
畫面中央以清晰的卡片矩陣展示所有庫房即時狀態：
> **【📷 建議截圖處 2】**：正常庫房卡片、警報中庫房卡片、離線庫房卡片之對比特寫。

* **卡片頂部色彩邏輯**：
  * 🔵 **常態藍色**：庫房運作正常，溫度在安全容許範圍內。
  * 🔴 **警報紅色 (外框呼吸閃爍)**：庫溫超標或設備故障，第一時間抓住視覺焦點。
  * ⚪ **離線深灰色**：設備未通電或通訊線路中斷。
* **中央大號數值**：
  * 即時顯示該庫房目前平均溫度（大字體，小數點後一位，單位 `°C`）。
* **設備運轉指示燈矩陣**：
  * 卡片下方配備動態指示燈號，代表該庫溫控主機的即時工作階段：
    * 🟢 **綠燈**：製冷中 (Cooling)
    * 🔵 **藍燈**：送風中 (Fan)
    * 🟡 **黃燈**：除霜中 (Defrost)
    * ⚪ **白燈/灰框**：壓縮機待機停機 (Stop)
    * 🔴 **紅燈閃爍**：設備硬體故障 (Error)
* **智能離線診斷提示**：
  * 當庫房處於離線狀態時，數值下方會精確標示原因，避免人員誤判：
    * `設備逾時 (網關在線)` ➔ 閘道器連線正常，請檢查該庫電箱電源或 485 訊號線。
    * `網關連線中斷` ➔ 閘道器掉線，請檢查 W610 電源與廠區 Wi-Fi。

### 2.3 廠區智慧電表總覽卡片
畫面下方橫向展示廠區集合式電表之電力消耗概況：
> **【📷 建議截圖處 3】**：智慧電表橫幅摘要卡片。

* **即時總功率**：顯示當前廠區低溫主機運轉之總負載（單位：`kW`）。
* **當月累積用電量**：統計當月 1 日至今之總耗電度數（單位：`kWh`）。
* **總平均電流**：即時三相平均電流值（單位：`A`），輔助監控負載是否過載。
* **平均線電壓**：三相供電平均電壓（單位：`V`），監控供電是否穩定。

## 第三章：單庫詳細控制面板操作指引

在主畫面上**點擊任一庫房卡片**，即可彈出該庫房的「詳細控制與遠端調溫面板」。

> **【📷 建議截圖處 4】**：單庫詳細控制面板彈窗（顯示各項壓力、電流、溫度輸入框與啟停按鈕）。

### 3.1 關鍵運轉參數即時監控
控制面板內部即時展示冷鏈設備的 6 大運行指標：
1. **控制溫度 (庫溫)**：庫房內主要感溫點之實際溫度。
2. **盤管溫度 (化霜感溫)**：蒸發器鰭片/盤管溫度，監控除霜是否徹底及結霜狀況。
3. **壓縮機運轉電流**：壓縮機主機實際抽載電流（單位：`A`），預防馬達過載或欠相。
4. **冷媒高壓壓力**：高壓側冷媒壓力（換算為工程常用 `psi` 單位），監控散熱效能與冷凝器狀態。
5. **冷媒低壓壓力**：低壓側冷媒壓力（換算為 `psi`），防止低壓過低引起冰塞或回液。
6. **今日累計運轉時數**：自動累計本日壓縮機製冷運轉時數，供保養排程參考。

### 3.2 遠端目標溫度設定 (Set Temperature)
操作人員可直接在大畫面上修改目標庫溫，指令將經由雲端自動寫入現場溫控器：
* **操作步驟**：
  1. 在「設定溫度」欄位中輸入新數值（系統限制於 `-60.0°C` 至 `+60.0°C` 之間）。
  2. 輸入完成後，右側「套用設定」按鈕將會點亮解鎖。
  3. 點擊「套用設定」，系統彈出確認對話框以防誤觸。
  4. 確認送出後，輸入框右側狀態指示燈將進行回饋：
     * 🟡 **黃燈閃爍**：指令已送至雲端排隊，現場閘道器正在寫入。
     * 🟢 **綠燈長亮**：現場設備已成功寫入，並確認生效！
     * ⚪ **灰燈復原**：逾時或寫入失敗，數值自動退回原始設定。

### 3.3 設備主機遠端起停控制 (Power On / Off)
* **起停按鈕**：提供「開機 / 停機」單鍵切換。
* **安全保護機制**：點擊切換時需經過二次確認，指令寫入現場溫控器的停控暫存器（A801 模式），確保維修保養時具備確定的起停控制能力。

## 第四章：警報監控與安全閥值管理

> **【📷 建議截圖處 5】**：警報設定視窗（高低溫閥值輸入、警報啟用開關）。

### 4.1 警報觸發機制
系統提供三重安全防護：
1. **高溫警報**：當庫房即時溫度連續高於「警報溫度上限」達設定延遲時間時觸發。
2. **低溫警報**：當庫房即時溫度連續低於「警報溫度下限」達設定延遲時間時觸發。
3. **設備硬體故障警報**：溫控器內部偵測到感溫棒斷線、壓縮機過載、冷媒洩漏或高低壓開關跳脫時，即時回傳 Fault Code 觸發警報。

### 4.2 警報管理操作
* **警報閥值設定**：
  * 管理人員可依不同季節或儲放貨品種類，自訂各庫房的「高溫限制」、「低溫限制」與「警報開關」。
  * 支援單庫自訂或全廠批次套用。
* **歷史警報日誌**：
  * 系統自動留存所有警報事件的「發生時間」、「解除時間」、「觸發溫度」與「異常類型」，供追溯異常原因。

## 第五章：歷史趨勢分析與數據報表匯出

點擊頂部功能列之「歷史分析 / 報表中心」，可進入數據分析模組。

> **【📷 建議截圖處 6】**：歷史溫度趨勢折線圖、多庫房對比介面。

### 5.1 歷史溫度曲線分析
* **時間跨度快速切換**：提供「1小時」、「6小時」、「24小時」、「7天」、「30天」等多種常用區間。
* **多庫房重疊比對**：可同時勾選多個冷凍庫房，觀察開門進出貨時各庫溫度的回溫速度與降溫斜率。
* **互動式數據探針**：滑鼠滑過曲線任意點，即時浮現該時間點的精確溫度、運轉狀態與時間戳。

### 5.2 電力走勢與能源管理分析
> **【📷 建議截圖處 7】**：電力即時功率曲線與日用電統計圖表。
* 整合 1F 與 3F 總電表，分析用電峰值、離峰時段與製冷耗能關聯。
* 協助廠區落實節能降耗，避開台電夏季尖峰電價時段。

### 5.3 食安稽核專用 Excel 報表匯出
符合 HACCP / ISO 22000 食品安全驗證與衛生局例行稽查標準：
* **操作流程**：
  1. 選擇欲匯出之庫房名稱。
  2. 選擇統計日期區間（例如：指定某月或特定週）。
  3. 選擇採樣間隔（每 5 分鐘、15 分鐘、60 分鐘）。
  4. 點擊「匯出專業 Excel 報表」。
* **報表特色**：
  * 自動產生精美抬頭、統計摘要（最高溫、最低溫、平均溫、合格率）。
  * 附帶清晰表格化記錄，列印即為標準檢查報表，無需額外加工處理。

## 第六章：日常維護與開關機標準程序

### 6.1 電視牆日常開關機作業
* **開機操作**：
  * 電腦開機進入 Windows 後，若已安裝開機自啟，系統將在 10 秒內自動在背景啟動服務並彈出滿版大畫面。
  * 若手動開啟，只需在桌面點擊 **【添利冷鍊監控系統】** 捷徑圖示即可。
* **關機作業**：
  * 若需關閉監控電腦，直接點選螢幕右上方關閉按鈕，或在系統目錄執行 `stop_local.bat` 後正常關機。

### 6.2 網路故障與配電盤通訊自我檢查指引
當畫面上出現異常提示時，操作人員可按以下指引迅速釐清問題：
* **現象一：畫面上所有庫別都顯示「網關連線中斷」**
  * 檢查重點：廠區寬頻數據機/Wi-Fi 分享器是否斷線？現場 W610 電源插頭是否鬆脫？
* **現象二：只有特定一間庫房顯示「設備逾時 (網關在線)」**
  * 檢查重點：閘道器與網路完全正常！請至該庫房控制電箱，檢查該台溫控器電源是否開啟？電箱內 485 訊號端子（A+/B-）是否鬆動？
* **現象三：卡片顯示紅色「警報 (ALARM)」但設備有在線**
  * 檢查重點：庫門是否未關緊？蒸發器是否結霜過厚需要手動除霜？冷媒壓力是否正常？
