## 四、 測試驗證腳本與指令

### 1. 專屬乙太網路網關掃描腳本
- 檔案路徑：`tools/scan_eth.py`

### 2. 測試執行指令
```powershell
# 1F 全區單次點位掃描
python tools/scan_eth.py --host 192.168.68.200 --port 2000 --slaves 1-8

# 1F 全區持續 100 筆穩定度測試
python tools/scan_eth.py --host 192.168.68.200 --port 2000 --slaves 1-8 --count 100
```

- **連線成功率**：**`100.00%` (0 丟包)**
