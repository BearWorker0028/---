## 第一章：系統定位與整體架構總覽

### 1.1 系統定位
「添利智慧冷鏈監控系統」專為現代食品加工廠與低溫物流設計，融合物聯網（IoT）邊緣採集與雲端高可用雙核心架構。系統提供**地端電視牆大畫面即時戰情、行動端 LINE 智慧推播、雲端冷熱數據備援、毫秒級異常警報與遠端智慧調溫**的一體化解決方案。

### 1.2 雲地雙核心通訊拓撲
系統由五層鏈路緊密構成：
1. **現場硬體層**：各庫房低溫主機配備 IoT-627 溫控器，廠區總盤配備 SPM-3 集合式智慧電錶，經 RS-485 實體雙絞線走 Modbus RTU 協定。
2. **通訊網關層**：1F (GW1) 與 3F (GW2) 網關負責將 RS-485 訊號轉封裝為 TCP 封包，主動撥入雲端伺服器（Port 8801 / 1883）。
3. **雲端伺服器層 (GCP Cloud)**：部署於 Google Cloud Platform 雲端虛擬機，執行 24 小時不中斷的高速輪詢引擎，並受 VPC 防火牆白名單保護。
4. **雲端資料庫層 (Supabase)**：採用銀行級 TLS 加密的雲端資料庫，實現即時狀態同步與指令排隊機制。
5. **地端監控大畫面層**：廠區電視牆與管理電腦免安裝軟體，瀏覽器即開即用，秒級動態刷新。

## 第三章：單庫詳細控制面板與遠端調溫操作

在首頁（卡片或平面圖模式下）**點擊任一庫房卡片**，即可開啟該庫的【詳細控制面板】彈窗。

### 3.1 關鍵運轉指標解讀

控制面板彈窗同時展示該庫下掛之各台冷鏈主機（例如 1F 冷凍庫 A ~ E 機）：

| 監控參數 | 顯示範例 | 說明與巡檢標準 |
| :--- | :---: | :--- |
| **控制溫度** | `-16.6 °C` | 庫內主感溫棒回報之實際溫度 |
| **盤管溫度** | `-21.7 °C` | 蒸發器鰭片溫度，除霜時會升溫，製冷時低於控制溫 |
| **運轉電流** | `76.1 A` | 壓縮機主機實際負載電流，用以判斷是否超載或欠相 |
| **高壓壓力** | `221.4 psi` | 冷媒高壓側壓力，監控冷凝器散熱狀況（正常約 180~250 psi） |

| **設備起停** | 🟢 (開) | 主機運行啟用開關 |
| **主機運轉時數**| `74.7 hr` | 累計運轉總時數，作為週期保養更換冷凍油之依據 |
| **設備狀態** | 🔵 製冷 / 🟢 送風 | 即時工作階段標籤 |

---

### 3.2 遠端調溫標準作業流程 (SOP)

```
[點擊庫房卡片] ➔ [輸入設定溫度] ➔ [點擊「送出」] ➔ [二次確認對話框] ➔ [雲端排隊寫入] ➔ [現場設備確認更新]
```

1. 在目標主機的【設定溫度】欄位輸入欲調整之目標數值（例：`-20.0`）。
2. 點擊輸入框右側的【送出】按鈕。
3. 畫面彈出防誤觸確認視窗，核對庫房名稱與設定值後點擊「確認」。
4. 系統將調溫指令推入雲端命令佇列，現場網關在下次輪詢時自動寫入溫控器 EEPROM。
5. 寫入成功後，介面數值即時更新為新設定值，無須人員親赴現場電箱調整。

## 第六章：庫溫歷史趨勢曲線與除霜判讀

點擊左側導覽列的【庫溫圖表】，可進入多維度溫度曲線分析模組。

### 6.1 功能操作重點
1. **多庫房多通道自由組合**：
   * 可透過下拉選單選取庫別、設備與資訊（控制溫度 / 盤管溫度），點擊【加入圖表】。

### 6.2 除霜週期特徵波形判讀技巧
* 正常冷凍庫運轉曲線呈現規律鋸齒狀（製冷打溫時緩慢下降，停機時微幅回溫）。

### 7.2 系統設定：門檻閥值與防抖設定

點擊左側導覽列的【系統設定】，彈出全廠參數配置視窗。

![系統設定 - 庫別溫度警報與校正設定](../前端定稿/螢幕擷取畫面%20(868).png)

#### 參數設定說明：
* **高溫警報 (°C)**：庫溫持續高於此門檻時觸發警報（例如：1F 冷凍庫設為 `-15°C`）。
* **低溫警報 (°C)**：庫溫異常過低時觸發保護門檻（例如：`-40°C`）。
* **延遲時間 (分)**：**防抖延遲機制**。預設為 `60 分鐘`，避免因人員進出庫短暫開門、或是主機正在除霜回溫時造成系統頻繁誤報。
* **啟用核取方塊**：勾選即啟用該庫房之自動監控發報功能。
* **溫度校正 (°C)**：當感溫棒因線路長度產生微小阻抗誤差時，可在此輸入偏移值進行軟體校準（例如：`0°C` 或 `+0.5°C`）。

## 第十章：日常維護與常見異常自主排除指引

### 10.1 電視牆日常開關機作業
* **開機操作**：
  * 開啟監控主機電源進入 Windows 桌面。
  * 雙擊桌面上的 **【裕珍皇冷鏈監控系統】** 捷徑圖示，系統將自動啟動地端服務並以全螢幕滿版載入大畫面。

  * **注意**：雲端監控主機 (GCP) 24 小時持續運作，地端電腦關機**不會中斷**數據採集與 LINE 警報推播。

### 10.2 常見異常現象與快速診斷對照表

```
                        異常診斷樹狀圖
                              │
            ┌─────────────────┴─────────────────┐
      [單一設備異常]                       [整層或全廠異常]
            │                                   │
     檢查該電箱溫控器電源                檢查 Wi-Fi 分享器與
    與 RS-485 端子 (A+/B-)            網關 (USR-W610) 變壓器
```

| **報表無法預覽或匯出** | 查詢日期區間無數據、或本地網路斷線 | 1. 確認基準日期與統計區間內設備有開機運轉。<br>2. 檢查本機電腦是否能正常連線至雲端 Supabase 資料庫。 |
