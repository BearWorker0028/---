### IoT-627 狀態旗標 16 位元完整解析 (Offset 34 / 40035 Bit Map)

| Bit | 位元名稱 | 中文狀態名稱 | 0 (OFF / 正常) 狀態 | 1 (ON / 觸發) 狀態 | 功能與動作說明 |
| :--- | :--- | :--- | :--- | :--- | :--- |
| **Bit 0** | `running_status` | **設備起停運轉狀態** | **0: 停止 (OFF)** | **1: 主機運轉中 (ON)** | 主機總體運轉/關機狀態指示 |
| **Bit 1** | `defrost_status` | **除霜運轉狀態** | 0: 非除霜 | **1: 除霜運轉中 (ON)** | 系統正在進行電熱/熱氣除霜動作 |
| **Bit 2** | `drip_status` | **滴水延遲狀態** | 0: 非滴水 | **1: 滴水延遲中** | 除霜終止後之融冰水滴水防凍延遲 |
| **Bit 3** | `fan_delay_status` | **風機延遲啟動** | 0: 無延遲 | **1: 風機延遲中** | 防止除霜熱氣吹入庫內之風機啟動延遲 |
| **Bit 4** | `high_temp_alarm` | **庫溫高溫警報** | 0: 正常 | **1: 高溫警報發報** | 庫內溫度高於警報上限閥值 |
| **Bit 5** | `low_temp_alarm` | **庫溫低溫警報** | 0: 正常 | **1: 低溫警報發報** | 庫內溫度低於警報下限閥值 |
| **Bit 6** | `defrost_heater` | **除霜電熱管狀態** | 0: 電熱關閉 | **1: 除霜電熱啟動** | 除霜電熱管加熱接觸器輸出 |
| **Bit 7** | `fan_status` | **蒸發風機運轉狀態** | 0: 送風停止 | **1: 風機運轉中** | 庫內蒸發器送風機接觸器輸出 |
| **Bit 8** | `cooling_status` | **壓縮機製冷狀態** | 0: 非製冷 | **1: 壓縮機製冷中** | 壓縮機運轉電磁閥/電磁接觸器輸出 |
| **Bit 9** | *(取消)* | *(低壓保護-已取消監控)* | - | - | 案場已取消此點位監控 |
| **Bit 10** | *(取消)* | *(高壓保護-已取消監控)* | - | - | 案場已取消此點位監控 |
| **Bit 11** | `phase_err` (L212) | **L212設備異常** | 0: 正常 | **1: L212設備異常** | IoT-627 L212 參數觸發之設備保護異常 |
| **Bit 12** | `sensor_err` (L213) | **感溫頭故障** | 0: 感測正常 | **1: 感測器開路/短路** | 庫溫/盤管感溫頭訊號斷線或異常 |
| **Bit 13** | `overload_err` (L214) | **馬達積熱過載** | 0: 積熱正常 | **1: 過載跳脫異常** | 壓縮機/風機過載積熱保護器動作 |
| **Bit 14** | `door_open` (L215) | **庫門開關狀態** | 0: 庫門關閉 | **1: 庫門開啟中** | 庫門極限開關觸發報警 |
| **Bit 15** | `equip_err` (L216) | **L216設備異常** | 0: 正常 | **1: L216設備異常** | IoT-627 L216 參數觸發之設備警報通知 |
