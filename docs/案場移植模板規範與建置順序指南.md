# 案場移植模板規範與標準建置順序指南 (v3.0)

> **核心定位**：將「裕珍皇專案」提煉為通用型工業冷鏈 SCADA ＋ 能源管理系統之標準工程模板（Blueprint），供未來所有新案場（食品廠、冷凍庫、物流中心）快速標準化移植複製。

---

## 🏗️ 第一部分：新案場標準建置順序 (7 大階段 SOP)

未來承接任何新案場時，嚴格遵循此 **「7 大階段黃金順序」** 推進，可達到 **0 重複返工、0 邏輯衝突、一次交付驗收**：

```
[階段 1：點位與暫存器收斂] ➔ [階段 2：採集與 SQLite WAL 儲存] ➔ [階段 3：衍生運算邏輯 (時數/電費)]
          │
[階段 4：電視牆 UI 與滿版引擎] ➔ [階段 5：警報生命週期與 LINE 推播] ➔ [階段 6：HACCP/台電報表引擎]
          │
[階段 7：雙向控制閉環 ＆ 案場主機一鍵交付包]
```

---

### 🔹 階段 1：點位表與暫存器規格收斂（輸入確認）
* **冷鏈溫控器（IoT627 等）**：確認各庫 Slave ID、Holding Register 位址（40001 庫溫、40002 盤管溫、40003 電流、40007 目標溫設定、40179 起停）。
* **電力電表（SPM-3 等）**：確認 CT 互感器變比（如 10x）、三相總功率 (kW)、累積底度 (kWh)、平均電壓 (V)、總平均電流 (A)。
* **產出**：填寫 `docs/監控點位與暫存器對照表.xlsx`。

### 🔹 階段 2：地端直採與雙模儲存引擎（後端骨幹）
* 部署 `collector/modbus_reader.py`（直連 W610 / Modbus TCP 網關）。
* 採用 **SQLite WAL 模式 (Write-Ahead Logging)** 作為地端默認儲存，配置 `PRAGMA synchronous=NORMAL`（突發斷電 0 損毀）。
* 建立資料庫表：`temperatures`、`power_readings`、`alarm_settings`、`alarm_history`、`device_commands`。

### 🔹 階段 3：核心衍生邏輯演算法（高階數據分析）
* ⏱️ **主機運轉時數 (`runtime_hours`)**：依壓縮機電流門檻（如 > 3.0A）且製冷中，進行高精度積分累積，斷電重開機自動繼承不歸零。
* 📊 **15 分鐘計費差值 (`delta_kwh`)**：$\text{kWh}_t - \text{kWh}_{t-15\text{m}}$ 對齊台電需量與計費週期。
* 🏷️ **台電三段式時段自動標籤 (`tariff_type`)**：自動判定尖峰（夏月夜尖峰 16~22 點）、半尖峰、離峰。

### 🔹 階段 4：前端電視牆與卡片/平面圖自適應引擎（視覺介面）
* **版面 3-1-1 統一 68px 卡片規範**：
  * 第 1 排：即時瞬時量（kW, V, A，三欄等高卡片）。
  * 第 2 排：單一大卡片「當月累積耗電量」（`min-height: 68px`，大字級 26px）。
  * 第 3 排：統計週期切換器。
  * 第 4 排：電費時段能耗橫條（`min-height: 68px`，尖峰/半尖峰/離峰）。
* **電視牆自適應引擎**：支援 6 種解析度（Auto, 1080P, 4K, 2K, 768P, 720P）等比縮放，支援 F11 滿版無邊框。

### 🔹 階段 5：警報生命週期與 LINE Flex Bubble 主動推播（安防通知）
* **生命週期管理**：連續 180 秒超溫確認 ➔ 觸發警報 ➔ 記錄 `alarm_history` ➔ 冷卻 30 分鐘防洗版 ➔ 庫溫復歸或門檻調高時**自動發送綠色復歸通知**。
* **LINE Flex Bubble 卡片**：🔴 高溫警報 (`#FF3B30`) / 🔵 低溫警報 (`#007AFF`) / 🟠 設備異常 (`#F97316`) / 🟢 恢復正常 (`#34C759`)。

### 🔹 階段 6：食安 HACCP 庫溫 ＆ SPM-3 能源報表引擎（合規稽核）
* **採樣頻率標準化**：嚴格鎖定 `1 分鐘` (異常分析) / `5 分鐘` (常規預設) / `15 分鐘` (台電/HACCP 標準)。
* **Excel 自動生成**：包含專業工程表頭、門檻基準、合格率、最高/最低/平均溫、超標次數與偏離時長，斑馬紋明細。
* **能源報表欄位**：累計用電單一數值（XXX.X kWh），選取能源報表時採樣頻率自動灰底鎖定為 15 分鐘。

### 🔹 階段 7：雙向設備控制指令閉環 ＆ 案場主機一鍵交付包（交付收尾）
* **控制面板 In-Place 原地更新**：聚焦中、手動修改中、下發鎖定中的輸入框 100% 不被 SSE 背景推播覆蓋。
* **閉環回執機制**：下發 40007 / 40179 ➔ 回讀確認相符 ➔ 標記 `success`。
* **案場主機打包**：提供 `start_local.bat`、`install_startup.bat`、`stop_local.bat` 與 `案場主機建置SOP.md`。
