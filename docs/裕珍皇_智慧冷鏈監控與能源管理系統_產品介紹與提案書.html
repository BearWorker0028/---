💡 系統定位與核心價值：
本系統專為食品冷鏈廠區量身打造，將傳統分散的人工抄表與被動維修，升級為「食安合規數位化、精準零誤報預警、電費避峰最佳化、主機健康預警」的四合一智慧中控平台。現場配置大螢幕電視牆與平面圖，遠端支援手機 LINE / Pushover 即時推播，為企業守護食材資產並實質節省營運成本。
🎯 四大核心價值（直擊業主管理痛點） Core Value Pillars
📋 1. HACCP / ISO 22000 稽核無痛合規
痛點：人工每日抄表耗工費時、易漏抄，衛生局或客戶查廠時常手忙腳亂。
  • 秒級擷取、每分鐘自動歸檔：數據真實且防篡改。
  • 一鍵匯出 Excel / 報表：依自選區間 10 秒輸出完整報表，大幅減輕品保工作負擔。
🛡️ 2. 庫溫聚合判定 ＆ 雙層預警防護
痛點：單機除霜就引發假警報（狼來了效應）；真正故障時卻無人知曉導致整庫食材報廢。
  • 庫別平均庫溫判定：單機除霜絕不誤報，全庫失溫立即發報。
  • 手機 LINE / Pushover 秒級推播：隨時隨地知曉異常。
  • 消音貪睡防呆機制：現場消音後若 10 分鐘仍未排除，蜂鳴音自動重響，確保問題被徹底解決。
⚡ 3. 能源管理與台電時間電價分析
痛點：夏季夜尖峰電價高昂（16:00~22:00），冷凍庫用電佔比極高，電費難以掌控。
  • 整合 SPM-3 集合式電錶：即時監控本日/當月累積度數（kWh）、功率（kW）、三相電流與 NFB 滿載跳脫預警。
  • 尖離峰自動分類分析：呈現「🔴 尖峰用電」與「🟢 離峰/半尖峰」佔比，協助落實「離峰蓄冷、尖峰避峰」，月省數萬電費。
🔧 4. 機組底層深度診斷與預防保養
痛點：冷媒洩漏、壓縮機老化往往等到完全不冷才發現，維修昂貴且影響生產。
  • 全方位運轉參數監測：盤管溫度、壓縮機運轉電流、高壓壓力、低壓壓力（bar/psi 雙制式）。
  • 累積運轉時數統計：實現預防性維護，延長壓縮機壽命。

🗣️ 業主常見問題與專業應對（Q&A） FAQ
Q1：如果廠區外網（網際網路）斷線，系統還能正常運作嗎？
A：完全不受影響！ 系統採用「邊緣運算（Edge Computing）」架構，本地主機具備獨立資料庫。即使外網中斷，現場依然 24 小時正常採集、記錄、警報與蜂鳴，待網路恢復後自動同步備份，資料零遺失。
Q2：現場人員會不會覺得介面操作很複雜？
A：極度直覺！ 介面採用國際標準圖形化設計：綠燈正常、藍燈製冷、橘燈除霜、紅燈警報。並具備全廠平面圖，現場人員不需繁瑣培訓，一眼就能看懂全廠冷鏈狀態。
Q3：如果有主機在正常除霜，會不會導致警報一直亂響？
A：絕對不會！ 本系統導入「庫別平均庫溫判定機制」，只有在整個庫別在線主機的平均溫度真正超標並持續超過設定延遲時才會警報；單台主機除霜時僅點亮橘色除霜燈，絕不引發假警報。
